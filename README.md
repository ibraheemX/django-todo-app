# Django Todo List App

A simple Todo List web application built with Django.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Responsive UI
- SQLite database

## Technologies Used

- Python
- Django
- HTML/CSS
- SQLite

## Installation

```bash
git clone <your-repository-url>
cd todo_project
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Project Structure

- `tasks/` → Main app for task management
- `todo_project/` → Django project settings and configuration
